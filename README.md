# Omato Food Delivery BI Dashboard

2-page interactive Power BI dashboard analyzing food delivery performance for Omato.

## Tools & Technologies
- Power BI Desktop
- DAX (Data Analysis Expressions)
- Power Query

## Dashboard Features
- 2 report pages
- 3 DAX measures
- 9 visual types
- 5 cross-page slicers
